HW8 – Topic Modeling and Document Clustering

This project applies unsupervised learning techniques to the CRANFIELD dataset.

## Components
- clustering.py → LDA topic modeling + KMeans clustering
- partition.py → clustering + evaluation using relevance judgments

## Dataset
- cran.all.1400 → document collection
- cranqrel → relevance judgments

## Techniques Used
- Latent Dirichlet Allocation (LDA)
- K-Means clustering
- Bag-of-Words representation

## Output
- Topic-word distributions
- Document clusters
- Cluster sizes

## Execution
python clustering.py
python partition.py
